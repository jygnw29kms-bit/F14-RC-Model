# F14 v109 hardpoint material coupon

This coupon reproduces the local front hardpoint geometry used by the v103-v106 center-wingbox candidate:

- 12 x 12 mm socket envelope
- 6.4 mm bore over the original 24 mm socket length
- 8 mm solid fork tail after the tube end
- 2 mm fork-style base tab

It is a **material/orientation screening coupon**, not a substitute for the full v107 module proof.

Print at least three copies per material/process:

1. **Production orientation** — fork plate flat on the build plate; crosstie Y-axis lies in XY.
2. **Side orientation** — rotate 90 degrees so one socket wall becomes the bed face.
3. **Z-control** — orient the long socket axis predominantly through Z; this intentionally exposes weak interlayer behavior and is not the intended production orientation.

For PPA-CF and PA6-CF, dry and print exactly according to the chosen qualified process. Record spool lot, drying time/temperature, chamber condition, nozzle, bed, layer height, wall count, infill, orientation and measured bore dimensions.

Use a smooth 6.0 mm proof pin. The coupon is comparative; full production release still requires the complete v105 module to pass v107 at 901 N front / 848 N rear proof loads.
