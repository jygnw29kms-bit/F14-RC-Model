## Ergebnis
Die UPC-Seitenansicht besitzt jetzt einen belastbaren **Engineering-Kandidaten** für die longitudinale FS-Registrierung. Die drei homologen Navy/UPC-Seitenlandmarken (FS93-Radomübergang, mittlerer Canopy-Bogen, hinteres Düsenende) ergeben einen konsistenten affinen Fit. Das ist ausdrücklich keine Fertigungsfreigabe.
