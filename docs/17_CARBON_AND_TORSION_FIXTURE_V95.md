# F-14 representative-joint carbon and torsion fixture — v95

v95 translates the continuous carbon reference into a buildable local specimen for the v94 representative joint. The coupon spans 40 mm around Y=363.9688 mm.

The current structural candidate uses two 1.0 mm carbon caps and an approximately 0.8 mm carbon web. Across the v94 specimen the cap width tapers from 10.8165 mm to 9.7540 mm and the web height from 3.6207 mm to 2.3231 mm. These values are geometry references, not yet material allowables.

A 250 mm lever is selected for the torsion fixture because the 2.24218 Nm sacrificial SF3 gate then requires 8.9687 N (0.9146 kgf) at the load line. The eventual non-destructive flight-article proof of 1.12109 Nm requires 4.4844 N (0.4573 kgf) at the same lever arm.

The fixture must support the printed skin with broad conformal cradles and apply torque about the local spar/joint axis. Both torque directions must be tested. The representative coupon must use the v93-qualified adhesive process and real carbon, not a printed carbon surrogate.

v96 will generate the conformal fixture bodies around the v94 coupon. Structural release remains false until the physical v93/v94/v95 tests pass.
