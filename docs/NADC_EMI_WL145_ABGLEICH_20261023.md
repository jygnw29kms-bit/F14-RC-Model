# NADC/EMI-WL145-Abgleich – 23.10.2026

## Ergebnis

Zwei voneinander unabhängige Quellen stützen für Studienzwecke einen globalen vertikalen F-14-Bezug nahe **WL 145 in**:

- NADC-81293-60 / AD-A124468, Figure 3: explizite Modell-Waterline **W.L. 12.1** im 1:12-Modell. Nominale Hochskalierung: **145,2 in**; allein aus der gedruckten 0,1-in-Modellauflösung ergibt sich ein Rundungsintervall von **144,6 bis 145,8 in**.
- NASA-F-14-EMI-Unterlage, Figure 16 „Aircraft Data“: **CENTROID WL = 145.0 in**, zusätzlich **BOTTOM WL = 120.0 in** und **FUSELAGE RADIUS = 34.0 in**.

Die beiden nominalen Werte unterscheiden sich nur um **0,2 in full scale**, entsprechend rund **0,234 mm im aktuellen RC-Maßstab**. Der EMI-Wert 145,0 in liegt innerhalb des NADC-Rundungsintervalls.

## Bedeutung

Das ist erstmals eine unabhängige Quellenkonvergenz für einen globalen vertikalen Referenzbereich um WL 145. Sie ist stärker als die frühere Übertragung aus einer Grumman-Wing-Referenzlinie, weil beide neuen Hinweise ausdrücklich als Aircraft/Model-Waterline bzw. Fuselage-Centroid-WL geführt werden.

## Was daraus ausdrücklich nicht folgt

Die lokale Achse der getrennt gezeichneten UPC-Sektion C ist dadurch **noch nicht** an WL 145 gebunden. Die EMI-Unterlage verwendet eine vereinfachte elektromagnetische Analysegeometrie, und die NADC-Unterlage beschreibt ein Testmodell. Daher gilt weiterhin:

- keine automatische C-Z-Translation,
- die frühere Diagnoseverschiebung von etwa +3,566 mm bleibt keine Geometriekorrektur,
- kein A–F-Loft mit absolutem Z,
- keine Master-, Druck-, Produktions- oder Flugfreigabe.

## Nächster technischer Schritt

Gesucht wird jetzt ein homologes vertikales Merkmal, das in der UPC-Seitenansicht und einer Quelle mit WL-145-Bezug eindeutig dieselbe physische Struktur beschreibt. Erst damit lässt sich die lokale C-Achse an das globale Aircraft-Z-System anbinden.
