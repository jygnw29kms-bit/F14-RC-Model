# F14 v96 torsion fixture

Four printable clamp bodies are supplied for the v94 representative wing-joint coupon: fixed upper/lower jaws and moving upper/lower jaws. The moving upper jaw carries the lever lug.

Line the jaw faces with about 2 mm EVA/neoprene or similar compliant sheet. Do not hard-clamp the thin wing shell.

Fixed clamp center: Y=353.9688 mm. Moving clamp center: Y=373.9688 mm. Each 18 mm jaw stops 1 mm short of the actual joint at Y=363.9688 mm.

The M4 through-bolts remain outside the shell. Tighten evenly only until the specimen cannot slip.

Use a rigid 20 x 3 mm aluminium flat bar, about 200 mm long, on the moving upper lug. The 1:1 SVG drilling template marks both 5.5 mm anchor holes and the load line. That load line is 250 mm from the measured spar torque axis.

At the marked load line:
- sacrificial SF3 test: 8.9687 N (~0.9146 kgf)
- later flight-article proof: 4.4844 N (~0.4573 kgf)

Test the sacrificial specimen in both torsional directions with a controlled load source/load cell. Fixture slip, fixture damage or shell crushing invalidates the test.
