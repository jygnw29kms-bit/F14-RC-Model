# v94 representative printed joint coupon

This folder contains the four printable bodies for a 40 mm local coupon centered on the actual right-wing segment joint.

Print with the same material, nozzle, orientation strategy and process intended for the flight model:
- inner wing skin crop
- outer wing skin crop
- v89 insert (includes the outboard rib/key insert body)
- inner rib

Measured CAD assembly gaps:
- insert to inner skin: 0.15634 mm
- insert to outer skin: 0.13837 mm
- insert to inner rib: 0.22001 mm
- insert to nearest carbon reference: 0.10785 mm

The three carbon bodies are retained in the v94 F3D as reference/keepout geometry and span the entire 40 mm coupon. They are intentionally not exported here as printable structural substitutes. v95 defines the real CFK fabrication/test arrangement.

Do not use the 2.242 Nm SF3 torsion gate on a printed-only coupon and interpret failure as the final structural result. The full representative test requires the real carbon load path and the adhesive process qualified by v93.
